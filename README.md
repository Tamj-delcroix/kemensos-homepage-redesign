# Kemensos Homepage Redesign

**Konsep redesign homepage website yang terinspirasi dari situs institusi pemerintahan Indonesia.**

A homepage redesign concept inspired by Indonesian government institutional websites, focusing on a clean, modern, and responsive user experience.

## 🇮🇩 Tentang Proyek

Kemensos Homepage Redesign adalah proyek frontend yang berfokus pada eksplorasi desain ulang halaman utama website bertema institusi pemerintahan, khususnya bidang pelayanan dan kesejahteraan sosial.

Proyek ini bertujuan menghadirkan tampilan yang lebih modern, bersih, responsif, dan mudah digunakan, tanpa menghilangkan kesan profesional yang sesuai untuk website institusi publik.

## 🇬🇧 About the Project

Kemensos Homepage Redesign is a frontend project exploring a redesigned homepage concept for a government institution, with a focus on public services and social welfare.

The goal is to create a modern, clean, responsive, and user-friendly interface while maintaining a professional institutional appearance.

---

## 🎯 Tujuan Desain / Design Goals

- **Modern & Clean** — Tampilan modern dengan tata letak yang rapi.
- **Responsive** — Menyesuaikan tampilan dengan desktop, tablet, dan perangkat mobile.
- **Easy Navigation** — Mempermudah pengguna menemukan informasi.
- **Professional** — Menggunakan gaya visual yang sesuai untuk institusi publik.
- **Accessible** — Memperhatikan keterbacaan, navigasi keyboard, dan kenyamanan pengguna.

---

## ✨ Fitur / Features

- Header dan navigasi website.
- Hero section dengan teks utama dan area gambar.
- Quick access untuk akses informasi penting.
- Kartu berita dan informasi.
- Bagian profil institusi.
- Kartu program dan layanan.
- Bagian pengumuman.
- Footer dengan tautan navigasi.
- Interaksi navigasi dan pencarian sederhana.
- Layout responsif untuk berbagai ukuran layar.
- Styling fokus keyboard dan dukungan preferensi reduced motion.

---

## 🛠️ Teknologi / Tech Stack

- **HTML5** — Struktur halaman website.
- **CSS3** — Styling, layout, animasi, dan responsive design.
- **Vanilla JavaScript** — Interaksi dasar tanpa framework tambahan.

Proyek ini tidak memerlukan backend, database, atau instalasi package tambahan untuk dijalankan.

## 🚀 Cara Menjalankan / Getting Started

### 🇮🇩 Bahasa Indonesia

1. Clone repository ini atau unduh source code-nya.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Buka file `index.html` langsung di browser, atau jalankan menggunakan ekstensi Live Server.
4. Website siap dijelajahi.

### 🇬🇧 English

1. Clone this repository or download the source code.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` directly in your browser or use the Live Server extension.
4. The website is ready to explore.

Tidak diperlukan instalasi dependency tambahan.
